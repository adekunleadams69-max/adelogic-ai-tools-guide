# Adelogic AI Tools Guide

A clean, modern, beginner-friendly web guide and directory for exploring practical AI tools, automations, and workflows.

## Features
- **Interactive Tool Directory**: Browse 20+ practical AI tools categorized by function (AI Brains, Creative & Media, Automation & Agents, Web Builders, Voice & Everyday Apps).
- **Instant Search**: Filter tools in real-time by keyword, use case, cost, or project phase.
- **Decision Matrix ("Which Tool for Which Job")**: Instant lookup guide to match tasks with the best tool.
- **Safety Principles**: Essential ground rules for API key management, permission limits, and cost control.

## Built With
- HTML5 / CSS3 / Vanilla JavaScript
- Modern responsive layout and typography
- Zero build tools or heavy dependencies required (loads cleanly in any web browser)

## Deployment
Can be hosted easily on Vercel, Netlify, or GitHub Pages.
